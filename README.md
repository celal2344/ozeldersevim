# Özel Ders Evim

Turkish private tutoring marketplace built with Next.js App Router, Supabase, shadcn/ui, React Hook Form, Zod, TanStack Query, Tailwind CSS, and Bun.

## Development

```bash
bun install
bun dev
```

Open `http://localhost:3000`.
